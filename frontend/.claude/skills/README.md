# Skills — frontend

Skills scoped to the mobile app. Anything here (`frontend/.claude/skills/<name>/SKILL.md`)
auto-loads only when working under `frontend/`, and Claude Code offers it with a `frontend:`
prefix.

Put a skill here when it is specific to the frontend — FSD structure, NativeWind/Expo, TanStack
Query / Zustand patterns, RN performance, i18n. If it applies to the backend too, use the
repo-root global scope (`.claude/skills/`) instead so both sides get it.

No frontend-only skills yet. The cross-cutting `edge-case-bug-hunting` skill lives in the global
scope and already covers the frontend's boundaries.
